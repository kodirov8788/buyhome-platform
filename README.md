# BuyHome Project

A real-estate platform concept for home renting and buying workflows, organized as a multi-part application with separate frontend and backend concerns.

**Live demo:** https://buyhome-project.vercel.app

## What This Project Shows
- Product thinking around marketplace and property discovery workflows
- Separation of frontend and backend responsibilities
- Business-domain work beyond tutorials or visual clones

## Why This Stack / Tooling
- **React** was chosen for dynamic property browsing and interactive UI flows.
- **Node.js** provides a practical backend foundation for marketplace features and service endpoints.
- **MongoDB** fits listing-oriented data where fields may evolve over time.
- **Tailwind CSS** supports fast delivery of a polished property-search interface.
- **Context-based state management** keeps the state layer lightweight for the current scope.

## Stack
- React
- Node.js
- MongoDB
- Tailwind CSS
- Context API

## Current Scope
- Frontend and backend directories are separated in the repository structure
- The project is framed around property discovery, renting, and buying workflows
- Documentation is being aligned to make the repo easier to evaluate from a hiring perspective

## Why It Matters For Hiring
This repository adds marketplace/product domain depth to the portfolio. It is useful for showing that the work is not limited to internal dashboards or simple landing pages.
